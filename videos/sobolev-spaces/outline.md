## Facts used
- (Weak derivative) u(t) = |t| is not differentiable at 0, but it has a weak derivative: the sign function (-1 for t < 0, 1 for t > 0).
- (Weak derivative) v is a weak derivative of u if integration by parts holds with v for every smooth test function.
  A weak derivative is unique only up to a set of measure zero.
- (Sobolev space) W^{k,p} is the set of u in L^p whose weak derivatives up to order k are in L^p.
- (Sobolev space) Its norm is built from the L^p norms of all these derivatives. It is a Banach space.
- (Sobolev space) W^{k,2} is written H^k. It is a Hilbert space.
- (Sobolev space) Sobolev spaces are the modern replacement for the classical C^k spaces, to look for solutions of partial differential equations.
- (Sobolev inequality) If pk > n (n: the dimension), the functions are continuous (Hölder continuous), after a change on a set of measure zero.
